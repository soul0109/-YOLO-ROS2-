> 日常执行顺序见 [`后续开发计划与建模攻关方案.md`](后续开发计划与建模攻关方案.md)。

```
inspection-robot/                 # 本地可叫此名；远程仓库名可能是 -YOLO-ROS2-

├── README.md                     # 对外门面
├── docs/
│   ├── README.md                 # 文档索引（读什么、改什么）

│   ├── 后续开发计划与建模攻关方案.md  # 主执行手册（常滚动修订）
│   ├── 当前进度.md               # 活文档：阶段勾选/阻塞/下一步
│   ├── 仓库结构说明.md           # 本文件
│   ├── architecture/             # 架构图
│   └── weekly-review/            # 周复盘
├── ros2_ws/                      # ROS2 工作空间
│   └── src/
│       ├── inspection_interfaces/  # msg/srv/action（协议先行）
│       ├── inspection_demos/       # ROS2 通信 demo（阶段 2，待创建）
│       ├── robot_description/      # URDF/xacro（阶段 3）
│       ├── simulation_worlds/      # Gazebo 世界（阶段 3）

│       ├── inspection_mission/     # 巡检任务/异常（阶段 6）
│       ├── navigation_config/      # Nav2/SLAM 参数与地图（阶段 4）
│       ├── llm_control/            # 自然语言任务（阶段 8）
│       └── inspection_bringup/     # 一键 launch 总装
├── web/
│   ├── backend/                  # FastAPI（阶段 7）
│   └── frontend/                 # Vue3 Dashboard（阶段 7–8）
├── models/                       # 权重大文件不入库，见 models/README.md
├── scripts/                      # check_env.sh、sync_from_share.sh 等
└── assets/                       # README 演示素材
```

## 包职责速查

| 包 | 阶段 | 职责 |
|---|---|---|
| `inspection_interfaces` | 1+ | Detection / AnomalyEvent / PatrolTask / RobotStatus |
| `inspection_demos` | 2 | pub/sub、service、action、TF demo |
| `robot_description` | 3 | 机器人模型与 RViz |
| `simulation_worlds` | 3–4 | 厂区世界与仿真 launch |
| `navigation_config` | 4 | 只放 YAML/地图，不 fork Nav2 源码 |
| `vision_perception` | 5 | `yolo_detector` / `object_localization` |
| `inspection_mission` | 6 | 巡检状态机 / 异常管理 |
| `inspection_bringup` | 全程 | 分层 launch 总装 |
| `llm_control` | 8 | 自然语言 → 结构化任务 |

## 约定

- **协议先行**：节点间只认 `inspection_interfaces`，不认实现细节
- **配置与代码分离**：Nav2/SLAM 只提交参数与地图
- **大文件不入库**：`*.pt` / `*.onnx` / rosbag / 数据集见 `.gitignore`
