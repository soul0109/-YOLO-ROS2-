# M2 / 阶段 5B 采集清单（D2）

> **本刀只定清单与元数据，不采满、不训练。**  
> 规范：[`M2-5B-数据集规范.md`](M2-5B-数据集规范.md) · 场景：[`巡检场景规格.md`](巡检场景规格.md) v0.1.1

**版本：** d2-v0.1 · **日期：** 2026-10-11

---

## 0. 采集纪律（与规范一致）

1. 每次连采一个 **`batch_id`**；划分 split 时整批进 train/val/test，**禁止邻帧随机拆**。  
2. **检测框**与**状态标签**分栏填写；状态不是检测类。  
3. **UNKNOWN** 按专用行采，勿事后把模糊图全改 FAIL。  
4. **独立 test 批次**采完并标注后写入 `test_batches.txt` 并冻结，再调参。  
5. 主距离 **1.2 m 正对**；扩展 1.0 / 1.5 m 单独勾选。

---

## 1. 几何与机位

| 项 | 约定 |
|---|---|
| 站点 | `A` / `B` / `C`（`patrol_route` 停车位） |
| 触发 | `gz model` 瞬移 `robot_v0`（**不开 Nav2**） |
| 距离 | 名义 **1.2 m**；扩展 **1.0 m**、**1.5 m** |
| 朝向 | 车头正对柜面（A/B ≈ yaw −π/2；C ≈ +π/2） |
| 分辨率 | **640 × 480**（与现相机一致） |
| GT 场景 | 推荐 `apply_vision_scene_gt.py --seed <N>`；漏液仅 B=`fixed_fail` |

## 2. 清单矩阵（勾选表）

> 数字为**最低建议图数**（可多不可少到宣称「清单完成」）。同一格可跨多个 `batch_id`，但 test 冻结时须能追溯。

### 2.1 常态覆盖（1.2 m 正对）

| ID | 站 | 距离 | 灯态意图（站级摘要） | 面板 | 漏液 | 最低图数 | 备注 |
|---|---|---|---|---|---|---|---|
| N-A1 | A | 1.2 | 含 green + 至少一非绿 | dark 或 lit | none | 20 | 可 seed 随机 |
| N-B1 | B | 1.2 | 含 red/green 等 | lit 优先 | **fixed_fail** | 30 | 漏液 FAIL 主来源 |
| N-C1 | C | 1.2 | **必须含 off** | lit 或 dark | none | 20 | 验证 off≠green |
| N-MIX | A/B/C | 1.2 | seed 多样 | 两态均有 | B fail / 他 none | 40 | 补总量 |

### 2.2 距离扩展

| ID | 站 | 距离 | 内容 | 最低图数 |
|---|---|---|---|---|
| D-10 | A/B/C | 1.0 | 各站至少 1；含 B 漏液 | 15 |
| D-15 | A/B/C | 1.5 | 各站至少 1；灯仍入画 | 15 |

### 2.3 状态专项（保证稀有态）

| ID | 目标态 | 最低图数 | 做法提示 |
|---|---|---|---|
| S-OFF | 至少一灯 `off` | 20 | seed 或强制 apply；相机确认暗 |
| S-RED | 至少一灯 `red` | 20 | |
| S-YEL | 至少一灯 `yellow` | 20 | |
| S-DARK | 面板 `dark` | 30 | |
| S-LIT | 面板 `lit` | 30 | |
| S-LEAK | `leak=fixed_fail` | 30 | **仅 B** |
| S-NOLK | `leak=none` | 30 | A/C 为主 |

### 2.4 UNKNOWN 专用（独立覆盖）

| ID | 类型 | 最低图数 | 做法提示 |
|---|---|---|---|
| U-PNL | 面板中间带 / 不可判 | 10 | 合成或曝光使 V 落中间带 |
| U-LEAK | 漏液青色占比中间带 | 10 | 小斑/擦除类 |
| U-LED | 灯不可分色 / 过弱 | 10 | 勿标成 green |
| U-OCC | 遮挡致不可判 | 5 | 局部遮挡灯或屏 |

### 2.5 难例（过曝 / 遮挡 / 模糊 / 漏检场景）

| ID | 难例 | 最低图数 | 期望标签纪律 |
|---|---|---|---|
| H-OVR | 过曝 / 强 bloom | 10 | 能判则标态；不能则 UNKNOWN |
| H-OCC | 遮挡（工具/自遮挡模拟） | 10 | 同上 |
| H-BLUR | 运动模糊 / 失焦模拟 | 10 | 倾向 UNKNOWN，禁止瞎标 green |
| H-MISS | 构图致小目标贴边/裁切 | 10 | 检测可能漏；状态不得默认 PASS |

### 2.6 对照与回归（已有资产可计入）

| ID | 来源 | 用法 |
|---|---|---|
| R-D1 | `bags/vision_d1_seed42` | 可入某一 batch 的副本；计入总量时注明 |
| R-COFF | `bags/vision_c_off` off/on 对照 | 回归 off 可分性；可入 val/dev，谨慎进 test |

## 3. 每张图元数据字段

每图一个 JSON sidecar（或表一行）。**必填**除非注明可选。

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema` | string | 建议 `vision_5b_frame_v1` |
| `image_id` | string | 稳定 ID，如 `{batch_id}_{station}_{seq:04d}` |
| `file_name` | string | 相对路径 `images/xxx.png` |
| `batch_id` | string | **划分原子**；同批同 split |
| `split` | string\|null | 冻结前可 null；冻结后 test 清单为准 |
| `station_id` | `A\|B\|C` | |
| `distance_m` | float | 名义停车距离 1.0/1.2/1.5 |
| `robot_pose` | object | `{x,y,z,yaw}` map |
| `frame_id` | string | 如 `camera_link` / `map`（位姿帧写清） |
| `image_stamp` | object | ROS `{sec,nanosec}`；可与墙钟分离 |
| `captured_at` | string | ISO 墙钟（可选但推荐） |
| `seed` | int\|null | `apply_vision_scene_gt` seed |
| `gt_scene` | object | 站级 GT：`leds[3]`,`panel`,`leak` |
| `states` | object | 标注状态（可与 gt 同；人工修订以 states 为准） |
| `states.leds` | string[3] | `green\|red\|yellow\|off\|UNKNOWN` |
| `states.panel` | string | `lit\|dark\|UNKNOWN` |
| `states.leak` | string | `none\|fixed_fail\|UNKNOWN` |
| `verdict_gt` | object | 可选：由规则从 states 导出的 PASS/FAIL/UNKNOWN |
| `detections` | array | `{class_name, bbox_xyxy, confidence?}`；**无状态字段** |
| `checklist_ids` | string[] | 命中的清单 ID，如 `["N-B1","H-OVR"]` |
| `hard_case` | string[] | `overexpose\|occlusion\|blur\|crop\|none` |
| `unknown_case_id` | string\|null | 如 `U_panel_ambiguous` |
| `notes` | string | 可选 |
| `annotator` | string | 可选 |
| `label_version` | string | 标注规范版本，如 `d2-v0.1` |
| `synthetic` | bool | **C2 起必填**（增强帧 `true`；原始采集 `false`）。C1 增强可用 `notes` 追溯 |
| `parent_frame_id` | string\|null | **C2 起**：增强帧必填父图 `image_id`；原始为 null |
| `transform_type` | string\|null | **C2 起**：如 `U_panel` / `H_OVR` / `simulated_missing_detection` |

**增强纪律：** synthetic 帧与 `parent_frame_id` **同 split**；正式 test **只用独立原始批次**，禁止用增强凑 test。

### 3.1 检测框约定

- `class_name` ∈ `indicator_light` \| `panel` \| `inspection_region`  
- `bbox_xyxy`：像素坐标，图像系，含边界裁剪  
- **禁止**在 `detections[].class_name` 写入 `FAIL`/`green` 等状态词  

### 3.2 示例（节选）

```json

  "schema": "vision_5b_frame_v1",
```

## 4. 批次与冻结检查单

采集执行时逐项打勾：

- [ ] 每批有唯一 `batch_id`，manifest 列出全部 `image_id`  
- [ ] 无「一批跨 train+test」  
- [ ] test 批次列表已写入并注明冻结日期  
- [ ] test 含：三站、1.2 m 主距、off、漏液 FAIL、UNKNOWN≥10、难例≥10  
- [ ] 抽查：检测类无状态词；UNKNOWN 图未标成 PASS  
- [ ] C-off：抽查 C/`off` 图肉眼非亮绿

## 5. C2 护栏（扩大采集）

| 规则 | 说明 |
|---|---|
| 目录 | 扩大采集用 `bags/vision_5b_c2/`（或带唯一 `run_id` 的子目录），**勿覆盖** `vision_5b_c1` |
| 清空 | `c1_collect_min.py` /后续脚本默认**不删**已有 batch；替换须显式 `--force` |
| 增强 | `suggested_split` 与父帧同侧（通常 train）；禁止建议进 val/test |
| H_MISS | `simulated_missing_detection` = 流水线用例，**≠** 真实 YOLO 漏检 |

## 6. 本刀非目标

不采满上表、不训模型、不改 Nav2/Web。未说「开 C2」前不扩大采集。
