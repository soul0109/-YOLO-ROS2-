# 开发历程（经验本）

> **只追加、不删改已确认正文。** 与「活文档」分工如下。

| 文档 | 职责 |
|---|---|
| [`../当前进度.md`](../当前进度.md) | **NOW**：阶段、阻塞、下一步；可整页替换 |
| **本目录** | **THEN**：里程碑日记、误路、证据路径；追加归档 |
| [`../阶段*-*复盘.md`](../README.md) 等专题 | 深挖一篇讲透（面试/排错） |
| [`../weekly-review/`](../weekly-review/) | 可选周日摘要，链到本目录条目 |

## 何时写一条

里程碑结束、重要否决、验收过关/翻车、对外交接定稿时：

1. 更新 `当前进度.md`（短）
2. **在本目录新增一条**（或在未确认条目标状态）
3. 深教训另开/链到专题复盘

## 条目模板（复制新建）

文件名：`YYYY-MM-DD-短标题.md`

```markdown
# YYYY-MM-DD 短标题

- **状态：** 已确认 | 待确认 | 已否决
- **阶段：** 4 / 5 / …
- **证据：** `bags/...` · commit `abc1234`
- **相关：** 链接专题复盘或阶段说明（可选）

## 当时目标
一句话。

## 现象 / 阻塞
看得见的事实。

## 试过什么（含否决）
- …

## 结论
一句话；未拍板的标「待确认」。

## 下次别踩
一条铁律即可。
```
