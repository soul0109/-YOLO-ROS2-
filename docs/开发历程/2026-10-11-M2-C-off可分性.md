## 当时目标

仿真 `off` 在相机上可与 `green` 区分；ROI 不再把 C 站 off 判成 green；正常 green 不被误伤。

## 现象 / 阻塞

seed42 站 C GT=`[off,green,green]`，相机三灯全亮绿；`mean_vmax` 三槽几乎相同（~190）。

## 试过什么（含否决）

- 复现：force `cabinet_c_led_1`→red 有效 → spawn 通路正常。
- **根因：** apply/world 对 off **省略 `<emissive>`**；Gazebo Classic 残留上一状态发光（绿）。
- **修复：** off/dark 显式 `emissive=0 0 0 1`（`apply_vision_scene_gt.py` + `test_room.world`）；ROI 补 `rel_to_row_max` 保险带。
- 否决：训 YOLO、Web、宣称 90%、并行「统一 ROI 入口」。

## 结论

同机位对照：slot0 `mean_vmax` off≈23.5 vs green≈191.6；C/A/B 均 `gt_match=True`。不宣称 90%。
