## 6. 不符合预期：你遇到的「前倾、看不到万向轮」

### 现象（2026-08-28 首次验收）

- 只看到蓝盒子和一侧黑轮
- 车向前倾，前角顶地
- 以为没有万向轮

### 原因（已修复 v2）

差速小车标准布局是 **后驱 + 前万向轮**（像购物车）：

```text
侧视（正确）：

         ○ 万向轮（车头 +X）
    ┌────────────────┐
    │    蓝车身       │
    └──●────────●────┘  ← 两驱动轮在车尾（-X）
    地面 ═══════════════
```

| 错误版本 | 现象 |
|----------|------|
| 万向轮在车尾 | 前轮栽地 |
| 驱动轮在车身中部、万向轮在车头 | **车尾悬空，车头万向轮被抬起来**（你第二次截图） |

修复：新增 `wheel_offset_x = -0.12`，驱动轮移到车尾；万向轮保持车头 `+0.14`。

## 7. launch 里四个节点干什么

```text
gazebo.launch.py          → 开仿真器 + empty.world
robot_state_publisher     → URDF → TF（仿真时钟）
joint_state_publisher     → 轮子关节角初值 0
spawn_entity.py           → 把机器人放进世界（z=0.05 略抬高再落下）
```

## 9. 常见问题

**Q: 只能看到蓝盒子？**  
A: 滚轮缩小 + 中键旋转视角；或 World → robot_v0 → Move to。

**Q: 和 RViz 看起来不一样？**  
A: Gazebo 有光照、材质；胎纹可能不如 RViz 清晰，正常。

**Q: 轮子为什么轻微滚动？**  
A: 不是故意设计的运动。spawn 时从 z=0.05 落下，连续关节（`continuous`）在 Gazebo 里可自由转；地面摩擦 + 物理求解会让轮子微调。胎纹是为 RViz 可见性加的，会让这点转动更明显。阶段 3.3 接 `/cmd_vel` 后才是「受控」滚动。

**Q: 顶栏黄字 EOL？**  
A: Gazebo Classic 将停更；本项目仍用 Classic 11，后续再迁移。
