## 注意（踩坑）

仓库目录名以 `-` 开头，bash 会把 `cd -YOLO-ROS2-` 当成选项。必须：

```bash
cd ~/-YOLO-ROS2-
# 或
cd -- -YOLO-ROS2-
```

更推荐克隆时改名（不影响远程）：

```bash
git clone git@github.com:soul0109/-YOLO-ROS2-.git inspection-robot
cd inspection-robot
```
