## 协作方式（宿主机改 / VM 跑）

- **宿主机 Cursor**（共享文件夹项目）：改代码 + 文档
- **VM** `~/inspection-robot`：编译 / 仿真 / 验收
- 改完代码后：`bash ~/inspection-robot/scripts/sync_from_share.sh`
- 共享源（二选一，脚本自动探测）：`/mnt/a_xm/...` 或 `/mnt/hgfs/a_xm/...`
- 挂载命令（重启 VM 后需重做）：`sudo vmhgfs-fuse .host:/ /mnt/hgfs -o allow_other`

## 注意（踩坑）

- 仓库名若以 `-` 开头，`cd -xxx` 会失败 → 已改名为 `inspection-robot`
- 每个新终端先 `source /opt/ros/humble/setup.bash`；编过工作空间后再 `source ~/inspection-robot/ros2_ws/install/setup.bash`
- turtlesim 要两个节点：`turtlesim_node`（窗口）+ `turtle_teleop_key`（键盘）
- VMware 共享默认挂到 `/mnt/hgfs/a_xm/...`，不是 `/mnt/a_xm/...`；`sync_from_share.sh` 已支持自动探测
- 文档分工见 `docs/README.md`；**不要**再建第四份总计划文档
