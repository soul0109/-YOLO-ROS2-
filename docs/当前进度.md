## 注意（踩坑）

- 仓库名若以 `-` 开头，`cd -xxx` 会失败 → 已改名为 `inspection-robot`
- 每个新终端先 `source /opt/ros/humble/setup.bash`；编过工作空间后再 `source ~/inspection-robot/ros2_ws/install/setup.bash`
- turtlesim 要两个节点：`turtlesim_node`（窗口）+ `turtle_teleop_key`（键盘）
- 阶段 2 demo 节点（`demos.launch`）与 3.3 同时跑会污染 ROS 图；测试前先 `pkill -f log_publisher` 或不开 demo
- 停不下来多半是 `cmd_vel_timeout` 崩溃或插件仍订阅 `/cmd_vel`；跑 `bash scripts/smoke_test_stage33.sh` 自测
- 键盘遥控：**evdev 模式**（`setup_keyboard_evdev.sh` + 重登）；TTY 回退为 W/S 点按锁定
- spawn 自溜：确认 `cmd_vel_timeout` 为 `use_sim_time:=false`；见阶段 3.3 FAQ
- Gazebo 视角：滚轮缩放；**中键拖动**旋转视角；World → robot_v0 → Move to 对准机器人
- 差速车布局：**驱动轮在后/中，万向轮在车头**，三点才稳
- 激光验收用 `lidar_test.world`（空世界 ranges 多是 max）；冒烟脚本 `gui:=false`，勿 `pkill -f gzserver`（会误杀脚本自身）
- **相机冒烟**：需要 OGRE 渲染（`DISPLAY`）；无 DISPLAY 时脚本尝试 `DISPLAY=:0`；激光不受此限
- **Git push**：`github.com` 被解析到 `198.18.x.x` 时 SSH 22 会断；改走 `ssh.github.com:443`（见协作文档）
- 文档分工见 `docs/README.md`；**不要**再建第四份总计划文档
