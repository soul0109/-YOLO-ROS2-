# M2 视觉场景资产盘点（粗标签）

> **口径：** 首切片 = 指示灯 + 面板 + 标准化漏液色块（[`巡检场景规格.md`](巡检场景规格.md) v0.1.1）。烟雾/异物暂缓。  
> **范围决策：** 选项 A — 灯/面板可控随机（W2）；漏液固定 1 处 FAIL（不参与随机）。  
> **最后更新：** 2026-10-11（D2：5B 数据规范 + 采集清单文档）

## 0. 状态枚举（勿扩）

| 对象 | YOLO 定位类 | 状态字段（ROI） | 枚举 |
|---|---|---|---|
| 灯 | `indicator_light` | `led` | `green` \| `red` \| `yellow` \| `off` |
| 面板 | `panel` | `panel` | `lit` \| `dark` |
| 漏液区 | `inspection_region` | `leak` | `fixed_fail`（仅柜 B）\| `none`（A/C） |

暂缓：烟雾、异物、框→map、AMCL 硬阻塞检测。未达 5B **勿宣称 90%**。

材质约定（世界/apply）：灯 `green/red/yellow` = 有色 `emissive`；`off` / 面板 `dark` = **必须显式** `emissive=0 0 0 1`（Gazebo Classic 省略标签会残留旧发光 → C 站假绿）。

## 1. 世界模型（Gazebo）

| 路径 | 说明 |
|---|---|
| `ros2_ws/src/simulation_worlds/worlds/test_room.world` | 柜位几何 + W1 默认静态色 |
| 漏液 FAIL | **仅** `cabinet_b_inspection_region`（固定；不进随机、apply 不改） |

布局：灯一排 `z≈0.52`，屏 `z≈0.32`（不重叠）。几何：灯 Ø8 cm；面板宽 30 cm；漏液无 collision。

**相机覆盖（纸面，D1 再实拍确认）：** 光心约 0.12 m；1.2 m 正对可见高度上限约 0.64 m，灯顶≈0.56 m / 屏 / 地面色块应可同框；1.0 m 时灯顶可能贴边。

## 2. W2 seed / GT 约定

| 规则 | 内容 |
|---|---|
| 随机范围 | 每柜 `leds[3]` ∈ 灯枚举，`panel` ∈ 面板枚举 |
| 不随机 | `leak`：B=`fixed_fail`，A/C=`none`；模型位姿固定 |
| 可复现 | 同一 `--seed` → 同一 `gt.json`（`sort_keys` 稳定序列化） |
| 约束 | 全局 ≥1 非 green 灯；≥1 `lit` 面板；≥1 `dark` 面板（不足则按脚本内固定顺序确定性修补） |
| 脚本 | `scripts/apply_vision_scene_gt.py` |

```bash
# 只写 GT（无需 Gazebo）
python3 ~/inspection-robot/scripts/apply_vision_scene_gt.py --seed 42 --gt-only \
  -o ~/inspection-robot/bags/vision_gt/gt.json

# 同 seed 两次应一致
python3 ~/inspection-robot/scripts/apply_vision_scene_gt.py --seed 42 --gt-only -o /tmp/gt_a.json
python3 ~/inspection-robot/scripts/apply_vision_scene_gt.py --seed 42 --gt-only -o /tmp/gt_b.json
diff /tmp/gt_a.json /tmp/gt_b.json && echo OK

# Gazebo 已起 test_room 后，按 GT 改灯/面板材质（漏液不动）
# 会打印 apply [1/12] ...；约 10–30s，勿中断（中断可能导致灯/面板缺失）
W=~/inspection-robot/ros2_ws/src/simulation_worlds/worlds/test_room.world
source /opt/ros/humble/setup.bash && source ~/inspection-robot/ros2_ws/install/setup.bash
# 终端 A: ros2 launch simulation_worlds gazebo_robot_v0.launch.py world:="$W"
python3 ~/inspection-robot/scripts/apply_vision_scene_gt.py --seed 42 --apply \
  -o ~/inspection-robot/bags/vision_gt/gt.json
# 成功结尾应有: applied LED/panel visuals; leak model left unchanged
```

示例（`seed=42`，亦见 `bags/vision_gt/gt_example_seed42.json`）：

```json
{
  "A": {"leds": ["green", "green", "yellow"], "panel": "dark", "leak": "none"},
  "B": {"leds": ["red", "red", "green"], "panel": "lit", "leak": "fixed_fail"},
  "C": {"leds": ["off", "green", "green"], "panel": "lit", "leak": "none"}
}
```

## 5. R1 ROI 规则 · UNKNOWN · C-off

| 项 | 路径 / 约定 |
|---|---|
| 规则 YAML | `ros2_ws/src/vision_perception/config/roi_rules.yaml` |
| `schema` / `roi_rules_version` | **接口协议版本**（现 `roi_rules_v1`）；C-off 等内容改动**不**强制 bump；规则正文以 git 中该文件为准（后续可加文件哈希） |
| 离线脚本 | `scripts/roi_judge_d1.py` · `scripts/c_off_verify.py` |
| 灯 | 固定三槽 ROI + BGR 主色 → `green\|red\|yellow\|off\|UNKNOWN` |
| off 绝对阈值 | `v90_max` / `mean_vmax_max`（依赖材质显式零 emissive） |
| off 相对保险 | `rel_to_row_max: 0.40`（内容变更，仍属 `roi_rules_v1` 协议） |
| 面板 | ROI 内 HSV-V → `lit\|dark\|UNKNOWN` |
| 漏液 | 地面 ROI 青色占比 → `fixed_fail\|none\|UNKNOWN` |
| 巡检 verdict | 灯非绿=FAIL；面板 dark=FAIL；漏液 fixed_fail=FAIL；任 UNKNOWN 保留 |
| UNKNOWN 用例 | `U_panel_ambiguous` / `U_leak_ambiguous` |
| C-off 对照 | `bags/vision_c_off/`：`stationC_seed42.png`（左灭）vs `stationC_led1_green.png` + `c_off_measurements.json` |

```bash
# ROI 判定（期望 A/B/C 均 gt_match=True；UNKNOWN×2）
python3 ~/inspection-robot/scripts/roi_judge_d1.py --unknown-demo

# C-off 对照（需 Gazebo；apply seed42 + 同机位 off/on）
python3 ~/inspection-robot/scripts/c_off_verify.py --capture
# 期望：C leds=['off','green','green']；slot0 mean_vmax off≪green；A/B 不误伤
```

**验收：** A/B/C 与 GT 一致；`off≠green`；green 不被相对阈值误伤；两条 UNKNOWN 可复现；**不**宣称 90%。

## 6. E1 站点事件 MVP（已交付）

| 项 | 约定 |
|---|---|
| 落盘根目录 | **`bags/vision_e1_demo/`**（与 D1 同属 `bags/` 运行产物，gitignore；不用 `artifacts/e1/`） |
| 文件 | `events.jsonl`（一行一事件）· `images/`（截图）· `manifest.json` |
| 脚本 | `scripts/e1_emit_events.py`（复用 R1 `roi_judge_d1` + `roi_rules.yaml`） |
| 到站语义 | 注入 `mission_id` + `station_id`；位姿来自 `patrol_route.yaml`；**不跑 Nav2** |
| 判定输入 | 结构化 `Decision`：`object_type/verdict/reason/roi_source/roi_rules_version/measurements` |
| `roi_rules_version` | = yaml `schema`（协议版）；≠「含 rel_to_row_max 的内容指纹」 |
| `confidence` | **检测框/fixture 置信度**（detector 侧）；ROI 未定义 `decision_confidence` 时为 `null`；**禁止**用 confidence 推导 verdict |
| `roi_source` | `fixed_window`；或 `detector_box`（假框路径，见 §7） |
| 去重键 | `mission_id + station_id + object_type` + 可配置时间窗（默认 60s）；跨 mission / station / object_type **不去重合并** |
| 时间字段 | `timestamp`（或语义等价 `created_at`）= **事件写入墙钟**；`image_stamp`= **图像 ROS 时间**；二者不同时钟，**勿相减算时差** |
| 字段纪律 | `verdict`=巡检结果；`status`=生命周期 `open\|acknowledged\|closed`；**禁止**把 id/reason 塞进 `description` |
| `model_version` | E1 无自训 → `null`；`amcl_error_m` 可 `null`，不硬阻塞 |
| 里程碑 | **E1 已冻结**；不扩 Web/事件模块；`bags/vision_e1_demo/` 产物不入库 |

```bash
# 自检（清空输出目录并断言 FAIL/图片/去重/UNKNOWN≠PASS）
python3 ~/inspection-robot/scripts/e1_emit_events.py --self-check

# 生成（默认站 B / seed42 D1 样张）
rm -rf ~/inspection-robot/bags/vision_e1_demo
python3 ~/inspection-robot/scripts/e1_emit_events.py
python3 ~/inspection-robot/scripts/e1_emit_events.py   # 同窗再跑：条数不变

cat ~/inspection-robot/bags/vision_e1_demo/events.jsonl
ls -la ~/inspection-robot/bags/vision_e1_demo/images/
# 期望：≥1 条 verdict=FAIL（漏液 leak_fixed_fail 与/或 非绿灯）；image_path 非空
```

**已知限制 / 口径（必读）：**

- **E1 ≠ 5B ≠ M2 退出**：只证明「判定→可追溯事件」，不证明检测准确率，**勿宣称 90%**。
- **固定窗结果 ≠ 实时检测闭环**：回放 D1 PNG + ROI 规则；未接相机节点 / 未自训 YOLO。
- `roi_source=detector_box`：**协议钩子 ≠ 真实 YOLO**；`confidence` 仅为框分。
- `timestamp` 与 `image_stamp` 勿混作同一时钟。
事件字段对齐滚动计划 M2，并显式增加：`verdict`、`roi_rules_version`、`source`、`amcl_error_m`（可 null）。

### 后续接框测试清单（I1 不因「未挪框」返工）

| 检查 | 期望 |
|---|---|
| 挪漏液框离开色块 | `cyan_frac` 应变小；不得仍 FAIL-as-漏液（视规则阈值） |
| 非法/退化框（空、裁剪后面积 &lt; 64 px） | **不得 PASS**（`UNKNOWN` / `roi_degenerate_or_empty`）；内部像素 `xyxy` + 边界裁剪 |
