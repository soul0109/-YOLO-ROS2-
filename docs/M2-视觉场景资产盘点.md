# M2 视觉场景资产盘点（粗标签）

> **口径：** 首切片 = 指示灯 + 面板 + 标准化漏液色块（[`巡检场景规格.md`](巡检场景规格.md) v0.1.1）。烟雾/异物暂缓。  
> **范围决策：** 选项 A — 灯/面板可控随机（W2）；漏液固定 1 处 FAIL（不参与随机）。  
> **最后更新：** 2026-10-11（W1：世界能表达缺态）

## 0. 状态枚举（勿扩）

| 对象 | YOLO 定位类 | 状态字段（ROI） | 枚举 |
|---|---|---|---|
| 灯 | `indicator_light` | `led` | `green` \| `red` \| `yellow` \| `off` |
| 面板 | `panel` | `panel` | `lit` \| `dark` |
| 漏液区 | `inspection_region` | `leak` | `fixed_fail`（仅柜 B）\| `none`（A/C） |

暂缓：烟雾、异物、框→map、AMCL 硬阻塞检测。未达 5B **勿宣称 90%**。

材质约定（世界）：灯 `green/red/yellow` = 有 `emissive`；`off` = 暗色且**无** `emissive`。面板 `lit` = 有 `emissive`；`dark` = 无。

## 5. W1 核查命令

```bash
W=~/inspection-robot/ros2_ws/src/simulation_worlds/worlds/test_room.world
# 灭灯：led_3 无 emissive（A）
sed -n '/cabinet_a_led_3/,/<\/model>/p' "$W" | grep -E 'emissive|ambient'
# lit 面板（B）
sed -n '/cabinet_b_panel/,/<\/model>/p' "$W" | grep emissive
# 固定漏液
grep -n 'cabinet_b_inspection_region' "$W"
# 几何
grep -E 'radius>0.04|size>0.30 0.01 0.15' "$W" | head
# Gazebo 目视（独立终端；键盘遥控另开 WASD，勿嵌 launch）
source /opt/ros/humble/setup.bash && source ~/inspection-robot/ros2_ws/install/setup.bash
ros2 launch simulation_worlds gazebo_robot_v0.launch.py
# GUI：柜 A 右灯应暗；柜 B 面板发青光 + 柜前青色块；柜 C 右灯黄
```
