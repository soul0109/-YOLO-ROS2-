# 阶段 4.3：SLAM 建图（slam_toolbox + test_room）

> **性质：** 阶段 4 导航主链第一步——从传感器数据生成 **占用栅格地图**。  
> 前置：4.2a 通过、T3 轮径已确认（scale=1.0）。

**版本：** 2026-08-31

---

## 0. 这步在项目里干什么？你要巩固什么？

```text
/scan + /odom + TF  →  slam_toolbox  →  /map（占用栅格）
键盘遥控走一遍      →  地图覆盖三机房+走廊
map_saver           →  navigation_config/maps/test_room.yaml + .pgm
```

| 你要会 | 说明 |
|---|---|
| **SLAM vs 定位** | 建图模式发布 map→odom；AMCL 阶段用已有地图只做定位 |
| **TF 链** | `map → odom → base_footprint → laser_link` |
| **参数直觉** | `resolution` 5 cm；`min_laser_range` 对齐 robot_v0 的 0.30 m |
| **验收** | 地图能看清通道、三门、机房轮廓（不必美观） |

**真机要不要改？** 流程相同；真机 odom 漂移大时建图要慢走、多回环，或先 EKF（阶段 4 可选项）。

## 3. 建图操作

### 3.1 一键启动（推荐）

```bash
bash ~/inspection-robot/scripts/run_slam_mapping.sh --build
```

- 启动：Gazebo test_room + slam_toolbox + RViz（Fixed Frame = **map**）
- 本终端 WASD **慢速**走遍：充电 → 房 A → B → C → 走廊（与巡检环相同）
- RViz 里 **Map** 应随移动生长；**LaserScan** 红点贴墙

### 3.2 保存地图（另开终端，建图仍在跑时）

```bash
bash ~/inspection-robot/scripts/save_test_room_map.sh
```

产出：

```text
ros2_ws/src/navigation_config/maps/test_room.yaml
ros2_ws/src/navigation_config/maps/test_room.pgm
```

### 3.3 手动 launch（调试用）

```bash
ros2 launch navigation_config slam_mapping_test_room.launch.py
# 另开终端遥控：
ros2 run simulation_worlds keyboard_teleop.py
```

## 4. 配置文件

| 文件 | 作用 |
|---|---|
| `config/slam_toolbox_test_room.yaml` | slam_toolbox 在线建图参数 |
| `config/slam_mapping.rviz` | RViz：Map + Scan + TF |
| `launch/slam_mapping_test_room.launch.py` | Gazebo + SLAM + RViz |

**关键参数：** `min_laser_range: 0.30`（与 `laser_scan_min_range` 一致）；`max_laser_range: 8.0`（test_room 尺度足够）。

## 5. 常见问题

### RViz 里地图不生长？

1. Fixed Frame 是否为 **map**  
2. `ros2 topic hz /scan` 是否有 ~10 Hz  
3. 是否移动足够远（`minimum_travel_distance: 0.2`）  
4. 查 `/tmp/run_slam_mapping.launch.log`

### 地图有鬼影 / 双墙？

- 走太快、转弯太急 → 慢走、直角转弯前停车  
- test_room 穿缝问题已在 T1.6 修复；若仍有，查激光是否贴墙

### 保存失败？

- 建图 launch 必须仍在运行且 `/map` 存在  
- 需已安装 `nav2_map_server`
