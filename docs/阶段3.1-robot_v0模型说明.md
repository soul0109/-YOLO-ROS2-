## 2. 你启动后看到了什么

```text
ros2 launch robot_description display_robot_v0.launch.py
        │
        ├── robot_state_publisher   ← 读 URDF，发布 TF（各 link 相对关系）
        ├── joint_state_publisher_gui ← 左上角小框：手动拖轮子（见下文）
        └── rviz2                   ← 3D 可视化窗口
```

### 2.1 左上角小框：Joint State Publisher GUI

| 项目 | 说明 |
|------|------|
| **是什么** | `joint_state_publisher_gui` 节点弹出的调试窗口 |
| **干什么** | 手动拖动 `left_wheel_joint` / `right_wheel_joint` 滑块，模拟轮子转角 |
| **为什么需要** | 驱动轮是 `continuous` 关节，会转；RViz 需要知道「当前转角多少」才画对轮子姿态 |
| **数据流** | 滑块 → `/joint_states` 话题 → `robot_state_publisher` → 更新 TF → RViz 轮子跟着转 |
| **以后还用吗** | 真机/仿真时由**驱动插件**或**电机编码器**发布 `/joint_states`，这个小框可以关掉 |

**试一下：** 拖左轮滑块，RViz 里左轮应跟着转；点 **Center** 回零，点 **Randomize** 随机姿态。

**为什么只有 2 个滑块？** 万向轮 `caster_joint` 是 `fixed`（固定），车身 `base_joint` 也是 `fixed`，它们不需要手动调角度。

### 2.2 RViz 主窗口

| 元素 | 含义 |
|------|------|
| 灰色网格 | 地面（`base_footprint` 所在的 XY 平面） |
| 蓝色方盒 | `base_link` 车身 |
| 黑色圆柱 | 左右驱动轮（侧面看可能和车身重叠） |
| 灰色小球 | `caster_link` 后万向轮 |
| 彩色坐标轴 + 文字 | TF 坐标系（红 X、绿 Y、蓝 Z） |
| 左侧 Displays | 勾选/关闭 Grid、TF、RobotModel 等图层 |

**Fixed Frame** 设为 `base_footprint`：以地面投影点为参考，符合导航习惯。

### 2.3 若看到多余的 `camera_link`

那是**阶段 2** 的 `static_tf_broadcaster` 还在跑。关掉旧 demo 再看干净的 TF 树：

```bash
# 查看是否有旧节点
ros2 node list

# 若还有 /static_tf_broadcaster，在 launch 终端 Ctrl+C，或：
ros2 lifecycle  # 或直接关掉跑 demos 的终端
```

阶段 3 加相机后，`camera_link` 会由 URDF 里的固定 joint 产生，不再用阶段 2 的 demo 节点。

## 4. URDF 核心概念（必记）

| 概念 | 作用 | 本模型示例 |
|------|------|------------|
| **link** | 一个刚体零件 | 车身、轮子、万向轮 |
| **joint** | 连接两个 link，定义相对运动 | 固定 / 连续旋转 |
| **visual** | 显示外观（RViz/Gazebo 看图） | 蓝 box、黑 cylinder |
| **collision** | 碰撞形状（物理引擎用） | 通常与 visual 相同 |
| **inertial** | 质量与惯性（Gazebo 防翻倒） | 阶段 3.1 先写估算值 |
| **xacro** | 带参数的 URDF 模板 | `wheel_radius` 等可改一处全局生效 |

### 4.1 关节类型（本阶段用到的）

| 类型 | 含义 | 本模型 |
|------|------|--------|
| `fixed` | 不可动 | `base_joint`、`caster_joint` |
| `continuous` | 可无限旋转 | `left/right_wheel_joint` |

## 6. 编译与运行（VM）

```bash
source /opt/ros/humble/setup.bash
cd ~/inspection-robot/ros2_ws
colcon build --packages-select robot_description
source install/setup.bash

# 语法检查
xacro $(ros2 pkg prefix robot_description)/share/robot_description/urdf/robot_v0.urdf.xacro > /tmp/robot_v0.urdf
check_urdf /tmp/robot_v0.urdf

# RViz 显示
ros2 launch robot_description display_robot_v0.launch.py
```

## 8. 初学者建议：怎么读代码

1. 先看 `robot_v0.urdf.xacro` 顶部参数块（改尺寸从这里入手）
2. 再看 `base_footprint` → `base_link` 的 `base_joint`（理解「车离地面多高」）
3. 看一个驱动轮：`left_wheel_link` + `left_wheel_joint`（理解 continuous + axis）
4. 最后看 `display_robot_v0.launch.py`（谁读 URDF、谁发 TF、谁开 RViz）

## 10. 常见问题

**Q: 轮子看起来嵌进车身里？**  
A: 调整 `wheel_center_z` 或 `wheel_radius`，重新 launch。

**Q: 没有 joint 滑块窗口？**  
A: 安装 `ros-humble-joint-state-publisher-gui`。

**Q: RViz 里 RobotModel 报错？**  
A: 确认已 `source install/setup.bash`，且 `robot_state_publisher` 在运行。
