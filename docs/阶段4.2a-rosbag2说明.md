## 0. 这步在项目里干什么？你要巩固什么？

T3 只录了 `/odom` + `/ground_truth` 做里程计体检。**4.2a 录完整感知链**，为后面 YOLO 离线调试、问题复现、作品集演示打底。

### 0.1 系统分层

```text
在线（Gazebo 跑着）  遥控 → /cmd_vel → 底盘 + 传感器 → 四话题 + TF
录制（rosbag2）      把上述话题落盘 → bags/inspection/
离线（bag play）     不启 Gazebo，重放话题 → rqt / 自写节点订阅
```

**真机要不要 bag？** 要。现场问题往往靠「录一段 bag 回家慢慢调」；仿真先练熟工作流，真机直接复用命令。

### 0.2 与 T3 bag 的区别

| | T3 | 4.2a（本步） |
|---|---|---|
| 目录 | `bags/odom_drift/` | `bags/inspection/` |
| 话题 | `/odom` `/ground_truth` `/tf` | `/cmd_vel` `/odom` `/scan` `/camera/image_raw` `/tf` |
| 目的 | 量化里程计漂移 | 全链路离线复盘 |
| 体积 | 较小 | 较大（含图像） |

### 0.3 作品集 / 面试能讲什么

- rosbag2 录制、回放、`ros2 bag info` 查元数据  
- 知道哪些话题进 bag、为什么带 `/tf`  
- 离线用 bag 调 YOLO 节点，不必每次开 Gazebo

## 1. 录制话题清单

| 话题 | 类型 | 用途 |
|---|---|---|
| `/cmd_vel` | `geometry_msgs/Twist` | 复盘你发了什么速度指令 |

## 2. 操作步骤

### 2.1 一键录制（你在 VM 跑）

```bash
bash ~/inspection-robot/scripts/record_inspection_bag.sh
# 或首次 / 改过包：加 --build
# 省资源不看相机窗口：--no-rqt
```

- 黄充电垫出生，WASD 走巡检环（同 T3 路线）  
- 建议录 **1~3 分钟**；走完 **Ctrl+C**  
- bag 路径示例：`bags/inspection/run_20260831_HHMMSS/`  
- **把终端打印的实际路径记下来**（不要抄 `YYYYMMDD` 占位符）

### 2.2 查看 bag

```bash
ros2 bag info ~/inspection-robot/bags/inspection/run_YYYYMMDD_HHMMSS
```

应看到四话题 + `/tf`，时长与录制时间一致。

### 2.3 回放

```bash
# 基本回放
bash ~/inspection-robot/scripts/play_inspection_bag.sh \
  ~/inspection-robot/bags/inspection/run_YYYYMMDD_HHMMSS

# 弹相机窗口 + 自动抽样校验 scan/图像
bash ~/inspection-robot/scripts/play_inspection_bag.sh \
  ~/inspection-robot/bags/inspection/run_YYYYMMDD_HHMMSS --rqt --check

# 慢放 / 循环
bash ~/inspection-robot/scripts/play_inspection_bag.sh <bag_dir> --rate 0.5 --loop
```

`--check` 会在回放时确认 `/scan` 与 `/camera/image_raw` 收到有效消息。

### 2.4 自动化冒烟（无需手开）

```bash
bash ~/inspection-robot/scripts/smoke_test_stage42a_bag.sh
```

无手开、录 12 s → `bag info` → `play --check`。**2026-08-31 VM 已通过。**

> **注意：** Gazebo 相机插件需要渲染上下文，`gui:=false` 时 `/camera/image_raw` 不会出现；人工录制与冒烟均用 **gui:=true**（与 `record_inspection_bag.sh` 默认一致）。

> **注意：** 静止不遥控时 `/cmd_vel` 无消息，bag 里可能没有该话题；手开录环时 teleop 会持续发布，四话题齐全。

## 4. 学习问答

### 为什么回放时不启 Gazebo 也能看图？

bag 里存的是**已序列化的消息**，`ros2 bag play` 按时间戳重新发布到 ROS 图；订阅者（rqt、你的节点）与在线无异。没有物理仿真，但**数据是真实的录制结果**。

### `/tf` 为什么要录？

激光在 `laser_link`、相机在 `camera_link`、底盘在 `base_footprint`。离线做「图像像素 → 地图坐标」或检查 frame_id，需要回放时的 TF 树。

### bag 很大怎么办？

- 录短一点（1~2 min 够验收）  
- `bags/` 已在 `.gitignore`，**不要 commit 大 bag**  
- 截图 / `ros2 bag info` 输出作证据即可
