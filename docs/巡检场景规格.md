## 1. 场景概述

**场景名称：** 室内机房固定路线视觉巡检

**任务流程：**

```text
充电/起点 → 设备柜巡检点 A → 设备柜巡检点 B → 设备柜巡检点 C → 终点
```

共 **3 个设备柜巡检点**，固定路线、可重复验收。

## 4. 巡检几何（验算依据）

**相机高度 0.12 m**，**tan(半 VFOV) = 0.433**（VFOV ≈ 46.8°）。

| 项 | 数值 |
|---|---|
| 目标高度带 | **0.30 ~ 0.60 m**（中心 **0.45 m**） |
| 停车区 | 目标**正前方 1.0 ~ 1.5 m**，**车头正对**目标 |

**距离 → 可见高度上限（地面起算）：**

| 停车距离 | 可见高度上限 |
|---|---|
| 1.0 m | 0 ~ **0.55 m** |
| 1.2 m | 0 ~ **0.64 m** |
| 1.5 m | 0 ~ **0.77 m** |

**像素密度（1.2 m 处）：** **462 px/m**

| 目标 | 物理尺寸 | 约像素 |
|---|---|---|
| 指示灯 | 8 cm | **≈ 37 px** |
| 面板显示区 | 30 cm | **≈ 139 px** |

小目标下限：**≥ 20 px**（8 cm 灯在 1.2 m 处满足）。

## 5. 场景验收指标（替代纯技术指标）

| 类别 | 指标 |
|---|---|
| **到点** | 位置误差 **≤ 0.20 m** |
| **朝向** | 航向误差 **≤ 10°** |
| **停稳** | 到位后 **1.0 s** 内 \|v\| **< 0.02 m/s** 且 \|ω\| **< 0.05 rad/s** |
| **定位** | AMCL 定位误差 **≤ 0.10 m** |
| **任务** | **3 航点**单圈**无人工干预** |
| **异常检出**（阶段 5 定基准） | 检出率 **≥ 90%**（口径见 §5.1） |

### 5.1 异常检出率计算方法（v0.1.1）

- **分母：** 独立测试集中、属于 §3.1 首切片、带标准答案的样本（覆盖 PASS/FAIL/必要 UNKNOWN）。
- **分子：** 状态判定与标准答案一致的样本数（UNKNOWN 仅当标签为 UNKNOWN 时计正确）。
- **距离：** 优先 **1.2 m 正对**，再扩展 1.0–1.5 m；须声明测试集构成。
- **辅助指标（不替换 90%）：** 异常召回、误报率、逐类准确率——用于解释漏报/误报。
- **暂缓项**（烟雾/异物）不得计入首过 90% 的分子分母，直至规格再次升版纳入。

## 6. 传感器职责分工

| 传感器 | 职责 |
|---|---|
| **LiDAR** | 我在哪 / 哪能走 — 建图、定位、避障 |
| **相机** | 前面是什么 / 有无异常 — 检测 + 状态判断 |
| **YOLO**（阶段 5） | 只负责**找到目标在哪** |
| **ROI 分析**（阶段 5） | 指示灯颜色、面板亮灭、漏液色块等**状态判定** |

---

## 7. 对 `test_room` 建模的约束（阶段 4.1）

- 墙体、通道宽度满足 Nav2 footprint（≥ 1.2 m 走廊建议保留）
- **巡检目标物中心高度：0.45 m**（与目标高度带一致）
- 三个设备柜前各设停车区：目标正前方 **1.0 ~ 1.5 m**
- 指示灯（8 cm）、面板区（≈30 cm 宽）按 §4 像素密度布置
