## 三层协作（推荐固定）

```text
ChatGPT  → 改「执行计划」（任务怎么拆、建模怎么攻关）
Cursor   → 改代码 + 顺手更新「当前进度」
你       → VM 验收 + 勾选进度 + 周日写周复盘
```

## 阶段编号说明

- **日常执行以** [`后续开发计划与建模攻关方案.md`](后续开发计划与建模攻关方案.md) **的阶段 2–8 为准**（先 Nav2 再 YOLO，更贴近开发顺序）。
- **场景验收以** [`巡检场景规格.md`](巡检场景规格.md) **v0.1 指标为准**（到点/朝向/停稳/检出率，非「话题存在即过」）。
- [`项目执行计划.md`](项目执行计划.md) 中的阶段 4/5 顺序不同，作架构与背景参考即可，不必强行对齐。

## 完成证据（三类）

每个任务过关需同时留下：

1. 代码或配置（已 commit）
2. 可复制命令（写在进度或周复盘里）
3. 运行结果截图 / 日志

没有可验证证据，不视为完成。
