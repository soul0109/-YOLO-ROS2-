# 阶段 3.5 相机 — 排查交接（2026-08-30）

## 根因（已定位）

**URDF→SDF 合并时，`camera_joint` 上写 `rpy` 会导致：**

| 组件 | 合并后 pose（错误示例） |
|---|---|
| `camera_link` visual | `0.22 0 0.23 0 -1.5708 0` |
| Gazebo camera sensor | `0.22 0 0.23 3.14159 -1.57079 3.14159` |

→ **黑盒与视锥分离（悬空）+ 视锥朝天 + 画面全灰**

**修复原则：**

1. `camera_joint`：**只写 xyz，rpy 必须为 `0 0 0`**
2. 朝前旋转写在 `<gazebo reference="camera_link">` 的 sensor `<pose>` 里（写在 `<camera>` 之前）
3. 验收时对比 `gz sdf -p` 里 **visual pose 与 sensor pose 是否一致**

```bash
xacro ~/inspection-robot/ros2_ws/src/robot_description/urdf/robot_v0.urdf.xacro > /tmp/r.urdf
gz sdf -p /tmp/r.urdf | grep -A3 camera_link_visual
gz sdf -p /tmp/r.urdf | grep -A30 "sensor name='camera'" | grep pose
# 两者 roll/pitch/yaw 应相同
```

## 支架方案（2026-08-30）

```text
base_link
   ├── laser_link          x=0.05, z=0.07（不动，3.4 已验收）
   └── camera_mount_link   x=0.17, z=0.09（仅 visual 立柱+横臂，无 collision）
```
