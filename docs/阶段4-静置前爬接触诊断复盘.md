### 关键误判（教训）

1. **「抬摩擦压住位移」≠ 修好物理语义** —— mu=1.0 是压误差，改了运动学。  
2. **后轮高摩擦 ≠ 驻车刹车** —— `continuous` 关节可滚；摩擦防打滑不锁轴。  
3. **前球中心更低 ≠ 下坡** —— 半径小，底部与后轮同在 z=0。  
4. **同时改位置/惯量/阻尼** —— 失稳与运动退化无法归因；爆炸不能草率归因「惯量过小」后继续叠参。  
5. **真脚轮是正确长期方向，但不能在未验证布局时当灭火器** —— 先恢复可导航基线，再干净重做。  
6. **`pkill -f ros2` 会弄坏 ros2cli daemon**（`!rclpy.ok()`）；清场优先杀 `gzserver`/`gzclient`。

## 4. 机制（面试可讲）

1. 三点支撑：两驱动轮 + **fixed 前球**（不是真 caster）。  
2. 后轮接触带 `minDepth`/`maxVel`，前球原先缺省 → ODE 接触修正不对称。  
3. 数值残差表现为沿车头的微小前向冲量。  
4. 前球 mu=0.1 **允许**蠕变持续；后轮通过滚动配合位移。  
5. 对齐接触标签后，残差不再形成稳定前爬。  

**不是：** 重力沿坡推车、Nav2 暗中给速、差速插件单独「零速自转」。

## 6. 以后改物理的铁律

1. **单变量**：一次只改一类（接触标签 / 关节阻尼 / 几何），写对照表。  
2. **先 empty，后 Nav2**：定位蠕变不要混导航。  
3. **禁止**：用抬 mu、锁关节、叠惯量「肉眼不动」冒充修复。  
4. **真脚轮**：两关节（Z 转向 + Y 滚动）+ 安装空间分析 + 按尺寸算惯量；单独立项，勿与灭火混做。  
5. **install ≠ live**：改 xacro 后 `colcon build` + **重启 launch**；`verify` 查 live。  
6. 诊断脚本与模型语义保持同步（曾出现 verify 仍查 swivel 的事故）。
