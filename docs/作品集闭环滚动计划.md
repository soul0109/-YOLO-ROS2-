## 2. 范围决策：视觉首切片（已定）

### 2.1 第一版正式视觉验收（5B 闸门范围）

| 对象 | 首切片？ | PASS / FAIL / UNKNOWN |
|---|---|---|
| 指示灯 | ✅ | 绿 / 红黄灭 / 未检出遮挡等 |
| 面板 | ✅ | 有显示 / 黑屏 / 不确定 |
| 外观·漏液色块 | ✅ | 无异色块 / 有标准化色块 / 区域不可见 |
| 外观·烟雾 | ⏸ 暂缓 | 保留在总需求；5B 首过**不计入** |
| 外观·异物 | ⏸ 暂缓 | 同上 |

**规格动作：** [`巡检场景规格.md`](巡检场景规格.md) 升 **v0.1.1**，增加「实施切片」与「暂缓项」；v0.1 三类判据文字保留为总需求，避免静默降标。

### 2.2 YOLO vs ROI（职责冻结）

```text
YOLO：定位区域（indicator_light / panel / inspection_region）
ROI ：颜色/亮度/面积规则 → PASS | FAIL | UNKNOWN
事件 ：mission + station 上下文 → 结构化记录 + 截图
```

- 灯的红/绿/黄/灭 **不是** 四个检测类，是同一类框 + ROI。
- **UNKNOWN ≠ FAIL**；漏检不得默认为 PASS。

### 2.3 检测触发 vs AMCL 门禁（实现约束）

| 条件 | 用途 |
|---|---|
| 到站 + 停稳（GT/任务语义） | **可触发**拍照/检测 |
| AMCL ≤0.10 m | **单独质量字段**；不得作为「永远不检测」的硬阻塞 |

否则视觉写好了也会被未过的定位门禁卡死。

## 4. 里程碑（滚动主链）

> 周次 = 推进顺序，**不是**日历承诺。未达退出条件不得用「进入下一阶段」掩盖失败。

### M1 — 视觉基线成立（≈阶段 5A）

**目标：** 权重可加载；离线/节点可复现输出框与结构化检测；类别与数据缺口清楚。

| 任务 | 验收证据 |
|---|---|
| 固定轻量预训练权重（YOLO11n / YOLOv8n 等与依赖兼容） | `model_path` 非空；版本 + 文件哈希记录 |
| 跑通现有 `yolo_detector` | 框、类别、置信度、stamp、`frame_id`、耗时、标注图 |
| 建立自采仿真标注计划（灯/面板/检查区） | 类别定义文档；train/val/test 划分原则 |
| 盘点场景资产缺口 | 哪些状态已有模型、哪些要补 |

**退出：** 推理链路稳定；若预训练认不出柜上目标 → **转自采训练**，禁止盲目换更大模型碰运气。  
**明确：** 5A 过 ≠ 5B 过。

### M2 — 站点视觉 + 事件切片（≈阶段 5B + 6 MVP）

**目标：** 首切片 90% 口径可算；到站可触发；站点级事件可查询、可去重。

| 任务 | 验收证据 |
|---|---|
| ROI 规则可配置；UNKNOWN 有用例 | 规则 YAML + 反例图 |
| 独立测试集指标 | 状态准确率、异常召回、误报；**逐类**；首切片三类 |
| 相机或 bag 接入 | 节点消费 `/camera/image_raw` 不积压 |
| 事件最小字段 | 见下表；至少 1 条完整 FAIL 事件含截图 |
| 去重 | 同 mission+station+object+时间窗不刷屏 |

**事件最小字段：** `event_id`, `mission_id`, `station_id`, `timestamp`/`image_stamp`, `object_type`, `status`, `reason`, `confidence`, `station_pose`/`frame_id`, `image_path`, `model_version`

**退出：** 首切片达规格 90%（计算方法见场景规格 v0.1.1）；烟雾/异物未纳入不得声称「三类外观全过」。精确框→map **不做**。

### M3 — Web 最小产品 + 复现起步（≈阶段 7 MVP + 8 起步）

**目标：** Web 能发起/查看任务与事件；一次贯通演示可录屏；已知导航限制如实展示。

| 任务 | 验收证据 |
|---|---|
| FastAPI：任务 + 事件 CRUD/查询 | 重启后事件仍在 |
| Vue：任务状态、A/B/C 结果表、事件+截图 | 固定地图点位即可 |
| 演示脚本 | 环境检查 → 启动 → 验收步骤；WASD **独立终端** |
| 已知限制页/README 段 | 十轮 10/10 vs 2/10 写清 |

**暂缓：** 全分辨率视频 WS、复杂轨迹回放、LLM、ONNX/TensorRT、C++ 重写视觉。

## 5. 指标口径（阶段 5B）

正式门槛仍对齐场景规格：**检出率 ≥ 90%**（首切片范围 + 测试集定义写进 v0.1.1）。

辅助拆解（用于解释，**不替换**正式门槛）：

| 辅助指标 | 含义 |
|---|---|
| 异常召回 | 真 FAIL → 判 FAIL |
| 状态准确率 | 有标准答案样本中状态正确比例 |
| 误报率 | 真 PASS → 误判 FAIL |

测试优先 **1.2 m 正对**，再扩到 1.0–1.5 m；禁止只挑简单绿灯刷分。
