## 3. 对外部分析的采纳与修正

外部建议「冻结导航基线、开阶段 5、保留路线完成/精度未过」——**采纳**。

| 外部判断 | 本仓库核对 |
|---|---|
| 「全部失败都在 B」需纠正 | **同意**：run09/10 的 A 也超阈；run10 A+B 都失败 |
| accept 主因 ≠ 规划器 | **同意**：无规划失败证据；路线 10/10 |
| 主因排序偏定位/测量 | **同意作工作假说**：失败全是 `amcl_error`；B 停车准但 AMCL 偏大 → 「开不到」与「估计偏差」分开 |
| 测量窗可能未时间对齐 | **待验证 backlog**：station_gate 用最新 AMCL vs 当前 GT；尚未排除滞后 |
| map↔world 标定需独立证据 | **待验证 backlog**：先核实，不宣布转换错误 |
| 局部控制对 accept 主因低 | **同意倾向**：B 的 7 次定位失败中多数无 recovery，停车仍准 |
| 三项单变量实验顺序 | **写入 backlog，现阶段不执行** |
| 放宽 0.10 m 门槛 | **现阶段不做**；若改产品定义须显式声明，不得改写本批结论 |
