# 阶段 4.4：AMCL 定位（加载 test_room 地图）

> **性质：** 阶段 4 导航主链第二步——**已知地图**下用激光 + 里程计估计「我在地图哪」。  
> 前置：4.3 已保存 `maps/test_room.yaml` + `.pgm`。

**版本：** 2026-08-31

## 0. 这步在项目里干什么？你要巩固什么？

建图（4.3）回答：**环境长什么样** → `/map`  
AMCL（本步）回答：**机器人在地图上哪** → `map → odom → base_footprint` TF 链

```text
已有地图 /map
     +
/scan + /odom  →  AMCL 粒子滤波  →  /amcl_pose + map→odom TF
```

| 你要会 | 说明 |
|---|---|
| **SLAM vs AMCL** | SLAM **同时**建图+定位；AMCL **只定位**，地图固定 |
| **粒子云** | RViz 里 `/particle_cloud`：散=不确定，聚束=收敛 |
| **初始位姿** | 必须告诉 AMCL 大概在哪（`/initialpose` 或 RViz 2D Pose Estimate） |
| **闸门** | 定位误差 **≤ 0.10 m**（[`巡检场景规格.md`](巡检场景规格.md) §5） |

### 和前后步骤的关系

```text
4.3 SLAM     →  产出 test_room 地图（冻结）
4.4 AMCL     →  加载地图，验证定位（本步）
4.5 Nav2     →  用 map + AMCL 自动走到航点
```

**真机要不要 AMCL？** 要。仿真用 p3d `/ground_truth` 只是**验收尺子**；真机没有 ground truth，靠 AMCL + 激光。

## 3. 操作步骤

### 3.1 一键启动（推荐）

```bash
bash ~/inspection-robot/scripts/run_amcl_localization.sh --build
```

流程：

1. Gazebo test_room + 充电垫 spawn (0.9, 3.0)  
2. `map_server` 加载 `maps/test_room`  
3. `amcl` 启动粒子滤波  
4. RViz（Fixed Frame = **map**，地图 + 粒子云 + 激光）  
5. 自动发 `/initialpose`（充电垫）  
6. 本终端 WASD **慢走几步**，看粒子云聚束  

### 3.2 量化验收（另开终端，**静止**）

#### 操作清单（照着做）

| 步骤 | 谁 | 做什么 |
|---|---|---|
| 1 | 终端 A | `bash ~/inspection-robot/scripts/run_amcl_localization.sh --build` **保持运行** |
| 2 | 眼睛 | Gazebo + RViz 都起来；RViz 粒子云**聚成一束**（不散满地图） |
| 3 | 终端 A | **松开所有 WASD**，车停在黄充电垫，**不要动** |
| 4 | 可选 | RViz「2D Pose Estimate」再点充电垫；或 `publish_amcl_initial_pose.py` |
| 5 | 终端 B | `source` 后跑下面检查脚本 |
| 6 | 终端 B | **30 秒内双手离开键盘**，等脚本自己跑完、打印结果 |
| 7 | 判定 | 看 `max` 是否 ≤ 0.10 m |

**是的：开启后停着不动，等 30 秒出结果。** 不需要边走边测；边走边测误差会变大，不作 4.4 闸门依据。

```bash
source /opt/ros/humble/setup.bash
source ~/inspection-robot/ros2_ws/install/setup.bash
python3 ~/inspection-robot/scripts/check_amcl_accuracy.py --duration 30 --static-hint
```

应先看到 `OK: amcl_pose×... ground_truth×...`，再开始 30 s 采样。

**通过：** `max` 位置误差 ≤ **0.10 m**（mean / p95 作参考）。

#### 常见结果解读

| 现象 | 原因 | 处理 |
|---|---|---|
| `样本过少` / amcl_pose=0 | 仿真关了或未发 initialpose | 保持 A 终端运行；`publish_amcl_initial_pose.py` |
| mean 小、max 略超 0.10 | 转弯尖峰 | **静止重测**（官方闸门） |
| mean 大、边走边测 | 长按 W、地图与真值在远处偏差 | 静止验收；Nav2 用自动慢速 |

边走边测 mean≈0.17 m、max≈0.49 m **不代表 AMCL 坏了**——截图里持续 `前进` 时激光匹配跟不上 + 地图远处几何误差会放大。

### 3.3 粒子散了怎么办？

1. RViz 工具栏 **「2D Pose Estimate」**，点在**黄充电垫**上，箭头朝东（+X）  
2. 或手动：

```bash
python3 ~/inspection-robot/scripts/publish_amcl_initial_pose.py \
  --world-x 0.9 --world-y 3.0 --yaw 0
```

3. **慢速**直线走 1~2 m，给 AMCL 激光匹配机会

## 6. 学习问答

### 脚本一运行就退出？

旧版 `run_amcl_localization.sh` 在清理阶段用 `pkill -f 'amcl'`，会**误杀脚本自己**（路径含 `amcl`）。已改为只杀 `nav2_amcl/amcl`。另须在 **VM 普通终端**（Ctrl+Alt+T）运行，Cursor/无 TTY 环境会报「需要 TTY」。

### 为什么必须发 initialpose？

AMCL 是**全局定位**：粒子随机撒在地图上。不知道起点，粒子会遍布全图；给初值后粒子在充电垫附近生成，再靠 `/scan` 匹配墙收敛。

### AMCL 和 /odom 谁准？

短距离 **odom** 相对平滑；长距离 odom 会漂。AMCL 用激光把 `map→odom` **拉回**，让机器人在地图上的位置不漂。

### 验收为什么用 ground_truth？

仿真特权：p3d 直读真值，可自动算误差。真机用反光板 / 已知地标人工抽检。
