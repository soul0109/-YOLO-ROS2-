## 3. 柜体与停车点坐标

柜体 pose 为**几何中心**；停车点为**地面参考点**（将来 Nav2 航点雏形）。

| ID | 贴墙 | 指示灯 | 柜中心 (x, y, z) | 停车点 (x, y) | 建议车头朝向 |
|---|---|---|---|---|---|
| **A** | 北 (+Y) | 3×绿 | (1.5, 4.1, 0.6) | **(1.5, 2.7)** | -Y（面向柜 A） |
| **B** | 东 (+X) | 2绿 + 1红 | (6.1, 2.5, 0.6) | **(4.7, 2.5)** | -X（面向柜 B） |
| **C** | 西 (-X) | 2绿 + 1黄 | (-0.3, 2.5, 0.6) | **(1.1, 2.5)** | +X（面向柜 C） |

停车距离验算（柜正面 → 停车点）：均为 **1.2 m**（落在规格 1.0~1.5 m 带内）。

## 4. 启动命令

```bash
# 编译（首次或改过 worlds 后）
cd ~/inspection-robot/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select simulation_worlds
source install/setup.bash

# 方式 A：一键联调（Gazebo + rqt 相机 + WASD），换 test_room
bash ~/inspection-robot/scripts/run_gazebo_camera_teleop.sh --build --world test_room.world

# 方式 B：环境变量（默认仍为 lidar_test.world）
INSPECTION_GAZEBO_WORLD=test_room.world bash ~/inspection-robot/scripts/run_gazebo_camera_teleop.sh

# 方式 C：仅 launch（第二终端键盘遥控）
ros2 launch simulation_worlds gazebo_robot_v0.launch.py \
  world:=$(ros2 pkg prefix simulation_worlds)/share/simulation_worlds/worlds/test_room.world
```
