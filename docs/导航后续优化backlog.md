# 导航后续优化 Backlog（阶段 4 之后）

> **不是第四份总计划。** 总顺序仍以 [`后续开发计划与建模攻关方案.md`](后续开发计划与建模攻关方案.md) 为准。  
> 本文件只收纳「导航精度 / 恢复 / 测量」的**待做单变量实验**与产品尺讨论，避免和阶段 5 视觉主链搅在一起。

**基线冻结：** 见 [`阶段4-十轮验收收尾与已知限制.md`](阶段4-十轮验收收尾与已知限制.md)  
**对照证据：** `bags/patrol_stress_20261009_201804/`（先保存，不覆盖）

**原则：**

1. 每项实验**只改一个变量**；与冻结基线同协议重复测（建议 ≥10 轮或同口径分布对比）。
2. **保留随机扰动**；禁止用单次改善下结论。
3. 同时保留旧指标；新指标只做并列，不偷偷替换本批结论。
4. 未完成「测量可信」前，不优先猜规划器 / 换控制器。

---

## A. 三类动作（先分清再说「变好了」）

| 类型 | 例子 | 算不算定位提升 |
|---|---|---|
| 放宽尺子 | 0.10→0.13/0.15 m；删定位门禁；加长验收窗 | **否**；可改产品定义，须显式声明 |
| 修正测量 | 时间对齐 AMCL↔GT；独立核实 map↔world | **评估可信度↑**；机器人未必变好 |
| 真实提升 | 停稳后更新有效、观测参数改善误差分布、转场 recovery 下降 | **是**；须重复证据 |

---

## B. 建议实验顺序（最多先做三项）

### B1. 仅改诊断比较：同时间戳 AMCL↔GT

| | |
|---|---|
| 改什么 | `station_gate` / 诊断：增加 stamp 对齐误差；**导航与门禁逻辑不改**；旧指标保留 |
| 记什么 | AMCL stamp、年龄、误差方向、对应时刻 GT |
| 若同时间误差明显更小 | 支持**测量滞后**假说 |
| 若仍常超 0.10 m | 继续查**真实定位偏差** |
| 并行 | 坐标标定独立核实（`scripts/coords.py` / 地图 origin）：先举证，不默认转换错 |

**状态：** ⬜ 未做

### B2. 仅增加停稳后一次 AMCL 无运动更新请求

| | |
|---|---|
| 改什么 | 到站停稳后请求一次无运动更新；**不**重灌 initialpose、**不**用 GT 校正；保留原 ~1 s 验收窗 |
| 记什么 | 新消息是否到达；同时间误差是否下降 |
| 若改善 | 支持到站更新不足 |
| 若无新消息或误差不降 | 本实验不成立，回退该改动 |

**状态：** ⬜ 未做（依赖 B1 口径更清晰后更有说服力；也可与 B1 诊断并列观测）

### B3. 若前两项确认真定位偏差：仅试 `max_beams` 60→120

| | |
|---|---|
| 改什么 | **只**改 AMCL `max_beams`；其他 YAML 不动 |
| 记什么 | B 站同时间误差分布、B→C recovery、CPU/实时率 |
| 保留条件 | 误差**重复**下降且负载可接受；否则回退 |
| 说明 | 只增加激光抽样数，**不保证**有效 |

**状态：** ⬜ 未做（前置：B1/B2 已区分测量 vs 真偏差）

## C. 已登记、暂不排进主链的优化项

| ID | 现象 | 说明 | 优先级 |
|---|---|---|---|
| C1 | B→C recovery 频繁（7/10，合计 48） | 执行效率问题；与 accept 的 `amcl_error` **分开排**；终点通过不代表途中定位一直稳 | 中（阶段 5 后或演示卡顿时） |
| C2 | C 站 GT 停车 13.41–16.66 cm | 过 0.20 m 门槛但余量小 | 低 |
| C3 | 起步协议耗时长 | clear≈10s + spawn + 就绪 + TF warmup；属流程，非 Nav2 精度 | 低（工具体验） |
| C4 | IMU + `robot_localization` EKF | 执行手册可选项；不阻塞阶段 5 | 可选 |
| C5 | 换控制器 / 重搜门口 via | **冻结期内默认否决**；除非 B1–B3 证伪当前假说 | 冻结 |

## D. 重开导航调试的准入条件
